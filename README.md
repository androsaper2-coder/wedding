# Wedding Invitation Website

A romantic, mobile-friendly digital invitation with an animated envelope and wax seal.

## Edit your details
Open `config.js` and change:
- `groom`: groom's name
- `bride`: bride's name
- `initials`: letters shown on the wax seal
- `date`: wedding date
- `venueIntro`, `venue`, `time`: venue and time details

Save the file and refresh `index.html` to preview.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **Public** repository, for example `wedding-invitation`.
2. Upload all four files: `index.html`, `style.css`, `script.js`, and `config.js` (README is optional).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then press **Save**.
6. Wait a minute or two. GitHub will show your public invitation link in the Pages section.

Anyone with the link can open the invitation. To update it later, edit `config.js` directly on GitHub and commit the change.

## Notes
- Internet is needed for the decorative Google Fonts; the invitation itself is plain HTML/CSS/JS.
- Replace the placeholder bride name, venue, and time before sharing.
