# Andro & Margaret — Wedding Invitation

A responsive, animated envelope invitation for GitHub Pages. The included portrait is `andro-margaret-portrait.png` and is displayed inside the opened letter.

## Personalize
Edit `config.js` to change the names, date, venue and time. The current names are Andro and Margaret, the date is 01 · 05 · 2027, and the monogram is A & M.

## Publish / update GitHub Pages
1. Extract this ZIP.
2. Upload **all files inside this folder** to the root of your existing GitHub repository, replacing the old versions. Keep `index.html`, `style.css`, `script.js`, `config.js`, and `andro-margaret-portrait.png` together in the repository root.
3. Commit the changes. If GitHub Pages is already enabled, it will redeploy automatically.
4. Open your existing Pages URL and refresh.

The design adapts to phones and desktop screens.
